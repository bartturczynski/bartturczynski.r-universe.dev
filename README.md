# bartturczynski.r-universe.dev

Registry for <https://bartturczynski.r-universe.dev>.

Package sources live on GitLab under
[`bart-turczynski`](https://gitlab.com/bart-turczynski); this repository holds
only the `packages.json` registry that r-universe reads.

```r
install.packages("seor", repos = "https://bartturczynski.r-universe.dev")
```
